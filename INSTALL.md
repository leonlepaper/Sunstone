# Как поставить мод Sunstone

Мод для **Minecraft 1.21.1**, Java Edition, загрузчик **Fabric**.
На Bedrock (мобильная, консольная, Windows-версия из Microsoft Store) не работает.

## Что понадобится

| Что | Версия | Где взять |
|---|---|---|
| Minecraft | ровно 1.21.1 | официальный лаунчер |
| Java | 21 или новее | https://adoptium.net |
| Fabric Loader | 0.16.0 или новее | https://fabricmc.net/use/installer/ |
| Fabric API | 0.116.15+1.21.1 | https://modrinth.com/mod/fabric-api |
| Sunstone | 1.2.0 | `sunstone-1.2.0.jar` |

**Fabric API обязателен.** Без него мод не запустится — игра просто скажет,
что не хватает зависимости.

## Установка

1. Скачай и запусти **Fabric Installer** с https://fabricmc.net/use/installer/
2. В окне установщика выбери версию игры **1.21.1**, нажми Install
3. Открой папку `mods`:
   - Windows: `%APPDATA%\.minecraft\mods`
   - если папки нет — создай её
   - в сторонних лаунчерах (Prism, PolyMC, MultiMC) у каждой сборки своя папка `mods`
4. Положи туда **оба** файла:
   - `fabric-api-0.116.15+1.21.1.jar`
   - `sunstone-1.2.0.jar`
5. Запусти игру, выбрав профиль **fabric-loader-1.21.1**

Проверить, что всё встало: в главном меню зайти в «Mods» — там должен быть
Sunstone 1.2.0 с иконкой-розой.

## Игра по сети

Мод нужен **и на сервере, и у всех игроков** — он добавляет блоки и предметы,
поэтому одной стороны недостаточно. Версии должны совпадать.

## Что добавляет мод

Солнечная руда генерируется под землёй на высотах от −24 до 56, примерно там же,
где железо. Копается железной киркой или лучше.

```
рудный блок --добыть--> сырая руда --печь--> солнечный камень
                                                    |
    +-----------------------+-----------------------+
    |                       |                       |
    9 камней в сетке        8 камней + яблоко       8 камней + семечко пшеницы
    v                       v                       v
    блок солнечного камня   солнечное яблоко        солнечное семя
     (светит как факел)  (откат времени суток)
    |                                               |
 каменотёс                                 посадить на грядку
    v                                               v
полированный камень,               6 стадий роста -> солнечный цветок
ступени, полублоки                                  |
                                              зельеварение
```

**Солнечное яблоко** съедается как обычное, но отматывает время суток на 2000 тиков
назад. Есть можно при полной шкале голода, как золотые яблоки. Ночью не съедается —
за рассвет время всё равно не уйдёт.

**Строительные блоки** — блок солнечного камня, полированный вариант, ступени
и полублоки для обоих. Все светят на 14 единиц, как факел; форма на свет не влияет.
Крафтятся как ванильный камень или режутся каменотёсом.

**Зельеварение** идёт от мутного зелья, ингредиент — солнечный цветок.
Каждый следующий порядок добавляет к предыдущему, но действует меньше:

| Зелье | Из чего | Что делает | Время |
|---|---|---|---|
| Солнечный дистиллят | мутное зелье + цветок | «Спешка» | 1.5 мин |
| Дистиллят 2 порядка | дистиллят + цветок | то же плюс светишься вокруг себя | 1.5 мин |
| Дистиллят 3 порядка | дистиллят 2 + цветок | «Спешка II», свет — и загораешься | 30 сек |

Взрывные и оседающие варианты делаются как обычно — порохом и драконьим дыханием.

## Если не работает

- **Мода нет в списке** — проверь, что запускаешь профиль Fabric, а не обычный
- **Игра падает при запуске** — скорее всего забыт Fabric API
- **Ошибка про версию** — мод только под 1.21.1, на 1.21.4 или 1.20 не встанет
